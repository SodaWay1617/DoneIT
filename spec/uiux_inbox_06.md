# DoneIt: компактные входящие

Дата: 26 октября 2026. Референс: «Макет приложения DoneIt_ входящие на десктопе и мобильном устройстве.png».

## Представление

- `/inbox` использует отдельный шаблон; общий экран выполненных и закрытых задач сохранён.
- Один заголовок и общий молочный контейнер с компактными строками и разделителями. Название, проект, все личные теги и дата создания показаны без статуса NEW, описания и чекбоксов.
- На ПК дата справа, на телефоне под метаданными. Палитра, бейджи и стили меню переиспользуют компоненты дневного списка.
- Во входящих только обычные задачи NEW. Регулярки исключены из этого списка и счётчика. Их статусная модель не менялась; TODO для них по-прежнему запрещён.

## Действия и навигация

- Клик/короткое нажатие открывает стандартный редактор. Многоточие, правая кнопка мыши, Shift+F10/ContextMenu и долгое нажатие открывают одно меню.
- Ровно четыре действия: в бэклог, к работе, редактировать, отказаться (иконка X).
- «К работе» делегирует существующему сервису переноса: TODO и сегодняшний день из Clock приложения. Заданное время, интервал, дедлайн, оценка и теги сохраняются. У недатированной задачи не появляется придуманное время.
- Перенос в бэклог и закрытие используют существующие маршруты. Успех возвращает `/inbox` с выбранным проектом, обновляя серверный список и счётчики. При ошибке строка остаётся на месте, доступен повтор.
- Перед POST действует общий механизм обновления CSRF и проверки пользователя remember-me.
- Локальных фильтров нет. Входящие не наследуют скрытый фильтр planningType. Проекты выбираются в существующей навигации; ссылки сохраняют `/inbox`. В мобильном «Ещё» используется общий фрагмент списка проектов. В мобильную общую шапку входящих добавлена ссылка `+` на существующую форму создания (по умолчанию NEW).
- Редактор остаётся отдельной серверной страницей. SPA и сохранение через новый API не вводились.
- Первоначальная загрузка серверная: пустое состояние появляется только после получения списка, отдельного клиентского skeleton нет. Ожидание отправки действия обозначено состоянием busy строки.

## Проверки

- 305 Maven-тестов: без ошибок, падений и пропусков.
- Реальное локальное приложение: Chromium (Edge channel) и WebKit, ширины 320–1920 CSS px, RU/EN, длинные названия/теги, клавиатура, меню, жест с отменой при движении, переход к редактору.
- Проверены все три изменения состояния, повтор после HTTP 500 и восстановление remember-me перед действием после удаления JSESSIONID.
- Проверена эмуляция PWA и отступ от нижней навигации. Реальный iPhone Safari/PWA не проверялся.
- Скрипт и снимки: игнорируемые `target/inbox_browser_check.py`, `target/inbox-*.png`, журналы `target/inbox-*.log`.

Изменения не развёрнуты на VPS.
