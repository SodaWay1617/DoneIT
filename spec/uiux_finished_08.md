# DoneIt — «Завершённые», UI/UX 08

Дата: 30 октября 2026. Маршрут: `/finished`. Референс: «Референс - Завершенные.png».

## Область изменения

Раздел просмотра истории обычных и регулярных задач в DONE/CLOSED. Единое название «Завершённые» в RU и Completed в EN. Статусы и бизнес-операции не меняются.

- Общий светлый контейнер, радиус 16 px, нейтральные разделители, подсветка, компактные строки и общий компонент проекта/тегов из «Входящих» и «Бэклога».
- Рабочая область использует доступную ширину без старого ограничения 920 px.
- Строка-ссылка открывает существующий редактор. Нет быстрых действий, меню, чекбоксов выполнения и создания задачи в разделе.
- Название, бейдж DONE/CLOSED, проект, личные теги, существующий приоритет, регулярность, оценка и фактические списания. При отсутствии времени соответствующая строка не создаётся.
- У обычных задач дата строго completed_at для DONE и closed_at для CLOSED; null отмечается явно. У регулярной серии используется её существующее finished_at. Отдельные выполненные экземпляры активных серий не превращаются в новые записи архива.
- Факт — сумма записей времени задачи/серии с корректировками, как общий итог в карточке; это не персональный аналитический отчёт. Для старой обычной задачи без отдельных записей допустим её сохранённый spent_minutes. Даты не используются для вычисления факта.

## Фильтры и доступ

- Статусы: ALL/DONE/CLOSED; все три счётчика считают выборку с проектом и тегами, до ограничения выбранным статусом.
- Проект выбирается прежней навигацией. На этой странице её ссылки остаются в `/finished`, сохраняют теги/статус/размер и сбрасывают страницу.
- На desktop в навигации только этого раздела доступны личные теги; выбор нескольких имеет OR-семантику, согласованную с дневным списком. Между группами фильтров действует AND.
- На mobile — компактная кнопка и native dialog с проектом, тегами, статусом и сбросом.
- Чужой проект или личный тег дают 404; выборка и счётчики используют существующий TaskVisibility, включая режим SCHEDULE_ONLY.
- Контекст фильтров/страницы передаётся в редактор и возвращается после сохранения обычной задачи; для регулярки сохраняются существующие ограничения редактирования завершённой серии.
- Прежний planningType в URL поддержан для совместимости, отдельного фильтра планирования нет.

## Пагинация

- Размер 25 по умолчанию, разрешены 25/50/100. COUNT и SQL LIMIT/OFFSET используют общий предикат для UNION ALL обычных задач и серий.
- Порядок: дата завершения/закрытия DESC NULLS LAST, id DESC, тип задачи как дополнительный стабильный ключ при совпадении ID разных таблиц.
- В памяти только строки выбранной страницы; теги и время загружаются пакетно для её ID. На `/finished` отключены старые общие загрузки всех регулярок и назначений.
- Счётчики и страница читаются в одной read-only транзакции REPEATABLE READ. Слишком большой page ограничивается последней страницей, пустая выборка — первой. Недопустимый размер/статус и неположительная страница дают 400.
- На desktop — номера с ограниченным окном и многоточиями; на mobile — предыдущая/следующая, текущая и общее число страниц. Изменение фильтра или размера возвращает на первую страницу.

## Проверки

`FinishedTest` проверяет объединённую пагинацию, размеры, сортировку и null-даты, фильтры/счётчики/личные теги, чужой доступ и SCHEDULE_ONLY, записи времени с корректировками, пустые/невалидные состояния, редактор и локализацию. Общие проверки обновлённых списков и навигации выполняются вместе с ними.

Локальная проверка: полный прогон 329 тестов без ошибок, JAR собран. Chromium и WebKit прошли ширины 320/375/390/430/768/1024/1440/1920 px; проверены отсутствие горизонтального переполнения с длинными названиями, 25 строк страницы, номера и мобильная навигация, размер 50/100, фильтры проекта/тега/статуса, сброс страницы при изменении фильтра/размера, возврат из редактора, null-дата, отсутствие меню при правом клике/долгом касании, RU/EN и открытие входящих/бэклога. Проверочные сценарии и снимки находятся в игнорируемом target.

Новых миграций или UI-библиотек нет. Реальный iPhone PWA и выкладка на VPS остаются отдельными действиями.
