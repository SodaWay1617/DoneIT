Самая точная формулировка проекта

Я бы восстановил исходный замысел так:

DoneIt — это личная и семейная система, которая помогает не терять задачи, реалистично планировать дни, управлять backlog и проектами, видеть собственную нагрузку и постепенно превращать намерения в завершённые действия.

А путь развития выглядел примерно так:

V1
Ежедневные задачи + даты + backlog + статусы + переносы

V2
Реальное использование + исправление UX + архив

V3
Проекты + проектные backlog

V4
Подзадачи + повторяющиеся задачи

V5
Второй пользователь + семейные задачи

V6
Оценка времени + фактическое время + нагрузка

V7
Аналитика + отчёты + напоминания

V8
Календарь + более богатый интерфейс

Сейчас главный следующий шаг проекта — не добавление проектов или recurrence, а начать использовать текущий MVP каждый день. Иначе дальнейшие функции будут строиться на предположениях, а не на реальных проблемах.
